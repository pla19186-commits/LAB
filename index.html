สินค้า / รหัสขั้นตอนค่าเคมีผลรวมวัดทั้งหมดช่วงที่วัดได้ช่วง Specค่าเฉลี่ยปรับเติมทั้งที่ค่าอยู่ใน Spec

“เคยหลุด Spec” หมายถึงมีอย่างน้อยหนึ่งค่าที่วัดได้หลุดช่วง แม้ค่าเฉลี่ยอาจอยู่ใน Spec · ช่วงที่วัดได้คือค่าต่ำสุด–สูงสุดจริงหลังตัดค่าผิดช่วงกายภาพ · Remark ในแถวเดียวกันยังไม่ยืนยันผลก่อน–หลังปรับ

ตัวกรอง

ผลเทียบ Spec: ผ่าน = ค่าที่วัดได้อยู่ในช่วงทุกค่าที่มี Spec · ไม่ผ่าน = อย่างน้อย 1 ค่าหลุดช่วง · ไม่มี Spec = ไม่พบช่วงอ้างอิง · ไม่ทราบ Stage = ข้อมูลเดิมไม่มีขั้นตอน จึงจับคู่ Spec ไม่ได้
